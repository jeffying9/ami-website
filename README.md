# Atelier Mille Isole Website

This folder contains the first static website version for Atelier Mille Isole.

## Files

- `index.html` is the website content.
- `styles.css` controls the visual design.
- `script.js` controls the mobile navigation and header state.
- `AMI VI` contains the current logo assets.

## Current Positioning

AMI uses quality assurance as the central logic to guide product development,
prototyping, manufacturing, and China-based supply chain execution.
